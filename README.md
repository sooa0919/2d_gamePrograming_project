# 2d_gamePrograming_project

## 이동 테스트

Python과 `pico2d`가 설치된 환경에서 실행합니다.

```sh
python main.py
```

모니터 해상도에 맞춘 전체 화면으로 실행되며, 캐릭터는 128×128 크기로 표시됩니다.

- A / D: 좌우 이동 (idle 애니메이션 유지)
- A와 D를 동시에 누르면 정지
- 1: 느낌표 이모트 (9번째 줄 1~3칸)
- 2: 물음표 이모트 (9번째 줄 4~6칸)
- 이모트는 캐릭터 머리 위에서 약 1초간 재생됩니다.
- ESC 또는 창 닫기: 종료

배경의 12개 레이어를 순서대로 합성하며, 캐릭터는 화면 밖으로 나가지 않습니다.
이미지 경로는 코드 파일 기준이므로 다른 작업 폴더에서도 실행할 수 있습니다.
